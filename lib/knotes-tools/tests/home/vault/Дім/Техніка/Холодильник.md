# Холодильник

Samsung RB38T600FSA, куплений у 2019 році. Гарантія скінчилася.

- Температура: холодильна камера +4 °C, морозилка −18 °C.
- No Frost, розморожувати не треба.
- Ущільнювач дверцят морозилки трохи пропускає — записати майстра, коли буде час (контакти — [[Електрик Сергій]] радив свого знайомого).
