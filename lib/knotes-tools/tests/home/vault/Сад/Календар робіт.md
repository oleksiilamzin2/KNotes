# Календар робіт на дачі

| Місяць | Що робити |
|---|---|
| Березень | посів розсади томатів і перцю, обрізка дерев |
| Квітень | обробка саду від шкідників, посадка картоплі в кінці місяця |
| Травень | розсада в теплицю, огірки, полуниця цвіте |
| Червень | підв'язувати томати, полив, мульча |
| Липень | збір полуниці закінчено, огірки, перші томати |
| Серпень | томати, консервація |
| Вересень | картопля, яблука |
| Жовтень | садити часник, прибрати бадилля |
| Листопад | закрити сезон: вода, троянди, світло |
