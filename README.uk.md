# Knotes

[English](README.md)

Knotes — нативний застосунок для macOS, у якому нотатки лежать звичайними Markdown-файлами в
теці. Відкрийте теку, яка у вас уже є (сховище Obsidian підходить без змін), і отримаєте
швидкий редактор, пошук, що розуміє, про що ви питаєте, а за бажання й чат, який відповідає
на запитання про ваші нотатки.

Нотатки так і лишаються звичайними файлами. Knotes ніколи не замикає їх у базі даних: індекс,
який він будує, лежить поза текою, і його можна будь-коли видалити.

> Knotes — молодий особистий проєкт (версія 0.1). Інтерфейс поки лише українською.

## Що він уміє

**Писати**

- Живий перегляд, як в Obsidian: розмітка ховається скрізь, крім рядка, на якому ви зараз.
- Формули (LaTeX), зображення, сторінки PDF, таблиці, які редагуються як сітка, підсвічений
  код, задачі, блоки-callout, виноски.
- Нотатка, вбудована через `![[нотатка]]`, показується на місці, і її можна редагувати прямо
  там.
- Зберігає сам через дві секунди після того, як ви перестали друкувати. Якщо тим часом
  нотатку змінила інша програма, зберігаються обидві версії. Якщо зберегти не вдалося, Knotes
  про це скаже і не дасть закрити нотатку, не спитавши.

**Шукати**

- За назвою файлу, поки ви друкуєте.
- За словами в тексті, з формами слів української та англійської: `мовою` знаходить `мова`.
- За змістом, моделлю, яка працює на вашому Mac: «чим годувати кота» знаходить нотатку про
  котячий корм, навіть якщо в ній немає жодного слова із запитання.
- Зворотні посилання, згадки, які ще не стали посиланнями (одним натисканням стають), і зміст
  нотатки.

**Впорядковувати**

- Теки й теги, а ще вкладки, які лишаються до наступного запуску.
- Простори: іменовані кольорові набори тек, наприклад «Робота» і «Дім».
- Коли ви перейменовуєте чи переносите нотатку, усі посилання на неї оновлюються.
- Видалені нотатки чекають у «Нещодавно видалених» (30 днів, якщо не вибрати інакше).

**ШІ, якщо хочете**

- Чат із моделлю OpenAI на вашому власному плані ChatGPT, без API-ключа. Він читає нотатки
  через пошук і дає посилання на ті, якими скористався; змінювати їх він не може.
- Те, що ви вибрали, йому ніколи не показується: «Сховати від ШІ» в меню нотатки, файлу чи
  теки ховає її, а маленький сірий перекреслений мозок це позначає. (Під капотом нотатка
  отримує тег `#no-ai`, а тека чи PDF записуються в `.knotes.json` своєї теки.)
- MCP-сервер `knotes-mcp` дає ті самі інструменти (лише для читання) іншим агентам, наприклад
  Claude Code.

## Що потрібно

- Mac на Apple silicon з macOS 27 або новішою.
- Щоб зібрати: Xcode Command Line Tools, Rust 1.99 або новіший і cmake (скрипт налаштування
  ставить cmake через Homebrew).
- Для чату: план ChatGPT. Усе інше працює без облікового запису й без інтернету.

## Як зібрати й запустити

```sh
git clone https://github.com/oleksiilamzin2/KNotes.git
cd KNotes
scripts/setup.sh     # cmake і дві моделі для пошуку за змістом (близько 900 МБ)
scripts/bundle.sh    # збирає target/release/Knotes.app
open target/release/Knotes.app
```

Під час першого запуску Knotes попросить вибрати теку. Виберіть теку з нотатками (або сховище
Obsidian). Knotes індексує її у фоні, тож починати можна одразу.

Хочете просто спробувати без моделей? Тоді пошук за змістом вимкнений, усе інше працює:

```sh
cargo run --release -p knotes -- ~/шлях/до/нотаток
```

`bundle.sh` підписує застосунок вашим сертифікатом Apple Development, якщо він є (досить
безкоштовної особистої команди в Xcode). Без нього застосунок теж працює, але після кожної
збірки macOS знову питатиме дозволу, перш ніж чат зможе взяти свій вхід із в'язки ключів
(Keychain).

## Де лежать ваші дані

- **Нотатки** лишаються там, де були. Knotes додає лише файли `.knotes.json` (налаштування
  теки) і приховану теку `.knotes` зі вставленими зображеннями та нещодавно видаленими
  нотатками. Усе це переїжджає разом із текою через iCloud чи git.
- **Індекс, вектори для пошуку, розмови з чатом і вкладки** лежать у
  `~/Library/Application Support/Knotes`, поза вашою текою. Видаліть їх, і Knotes збудує їх
  знову.
- **Що покидає ваш Mac:** лише те, що йде через чат. Ваші запитання й уривки, які знайшов його
  пошук, надсилаються в OpenAI. Пошук за змістом працює на вашому Mac.

## Ваші нотатки в інших агентах

`knotes-mcp` лежить поруч із застосунком, у `Knotes.app/Contents/MacOS`. Один раз відкрийте
свою теку в Knotes (так збудується індекс), потім додайте сервер. Для Claude Code:

```sh
claude mcp add knotes -- /Applications/Knotes.app/Contents/MacOS/knotes-mcp ~/шлях/до/нотаток
```

Підставте шлях, де лежить ваш `Knotes.app`. Інші клієнти приймають ту саму команду й аргумент
у своїх налаштуваннях MCP. Інструменти лише читають: пошук, читання нотатки чи PDF, посилання,
нотатки за текою, тегом чи датою, задачі.

## Для розробників

Код — один Cargo workspace: бібліотеки в `lib/`, програми в `bin/`.

| Де | Що |
|---|---|
| `bin/knotes` | Застосунок, AppKit через `objc2` |
| `bin/knotes-mcp` | MCP-сервер |
| `bin/knotes-embed-helper` | Допоміжний процес, у якому працює модель ембедингів (llama.cpp на Metal) |
| `bin/knotes-gen`, `bin/knotes-bench` | Синтетичні сховища й бенчмарки |
| `lib/knotes-core` | Модель предметної області й трейти, які реалізує все інше |
| `lib/knotes-md`, `lib/knotes-index`, `lib/knotes-vault`, … | Markdown, індекс SQLite, файли, пошук, модель редактора, чат |

Чому все влаштовано саме так, записано в [`doc/adr`](doc/adr): одне рішення на файл, разом із
тим, що виміряли. Почніть із [0001](doc/adr/0001-workspace-layout-and-traits.md) про будову
і [0006](doc/adr/0006-performance-budgets.md) про бюджети швидкодії.

Тести:

```sh
cargo test --workspace                   # усе, разом із тестами вікна
cargo test --workspace --exclude knotes  # без тестів вікна: набагато швидше
```

Тести вікна сотні разів запускають справжній застосунок; його вікна тоді прозорі, а іконки в
Dock немає, тож вони йдуть у фоні й не заважають працювати. Тести, яким потрібні моделі для
пошуку за змістом, пропускаються (і кажуть про це), доки `scripts/setup.sh` їх не завантажить.

Бенчмарки на синтетичному сховищі:

```sh
cargo run --release -p knotes-gen -- target/vaults/50k --notes 50000 --seed 1
cargo run --release -p knotes-bench -- target/vaults/50k
```

На 50 000 нотаток на M5 Pro пошук за назвою займає менше 2 мс, повнотекстовий пошук — близько
10 мс, а індексація сховища з нуля — менше 7 секунд ([`doc/bench`](doc/bench)).

Ліцензії моделей і llama.cpp, які входять до застосунку, лежать у [`licenses`](licenses).
