# UI benchmark, 2026-11-12

Machine: Apple M5 Pro (ProMotion 120 Hz), macOS 27.2.1, release build, synthetic vault of
50k notes. Budgets: ADR 0006 (M1, so M5 numbers should be at most half).

| Measure | Result | Budget (M1) |
|---|---|---|
| Note list scroll, main-thread work per 40 pt step (3000 steps): p50 / p95 / max | 0.15 / 0.23 / 2.05 ms | 4 ms per frame (8.33 ms at 120 Hz) |
| Idle CPU after indexing settles (30 s) | 0.01 s CPU time, ~0.0 % | ~0 % |
| Idle wakeups | ~2.3 per second (was ~10 before removing the indexing thread's 300 ms poll) | no polling timers |
| Resident memory with the 50k vault open (warm start) | 245 MB | 300 MB |
| Physical footprint after a cold index of 50k notes (ADR 0014) | 158 MB (was 432–476 MB) | 300 MB |
| Closing a vault (session shutdown) | under 100 ms (was ~255 ms) | — |

How measured:

- Scroll: `KNOTES_PROBE=1 KNOTES_PROBE_ACTION=scroll-bench knotes <vault>`; each step scrolls
  the clip view, lays out and fills new rows and draws. GPU compositing is not included.
- Idle: `ps -o cputime` over 30 s and `top -stats idlew` over 20 s on the running app.
